# LAB-collage
This project is a job search webpage about myself. The initial idea of building this website actually came from my anxiety when I was looking for a job recently, but I didn't really want to make it a very negative or serious website, so I chose to introduce myself in a more relaxed and humorous way in the end. The webpage will include some basic information about me, photos, works, and some casual text, making it look a bit like a personal profile and collage, rather than a traditional portfolio website.

This website is mainly made using HTML and CSS. I used Grid, Flexbox, image positioning, and gradients to adjust the layout of the page, allowing text and images to be distributed more freely on the page.

During the production process, I used ChatGPT and Codex to help me write and modify some of the code, especially when adjusting CSS and solving layout issues. For example, I have asked "How to make the top image and white background naturally gradient together?" and "How to move the entire image grid to the right side of the webpage? ”Such issues. I will refer to the code provided by AI and continue to modify it according to the desired effect.

The theme, content, visual style, and final design of the website are all decided by myself, and AI is mainly used to help me solve problems encountered during the coding process.
